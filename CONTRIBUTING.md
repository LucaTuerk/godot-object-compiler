# How to contribute to godot-object-compiler

## Did you find a bug?

If you discover a bug with godot-object-compiler please open a bug issue with the following information:
* General System Information (OS, Architecture, Hardware)
* godot-object-compiler version, build number and configuration
* Detailed error description
* If possible: Provide a minimum reproducible project or example file.

If you discover a security issue please practice responsible disclosure and contact [the maintainer](https://github.com/LucaTuerk) directly
instead of opening a public issue.

## Suggesting features and enhancements

If you have a suggestion for features or enhancements open an enhancement issue, this allows contributors to align feedback and discuss before
significant implementation work is done.

## Submitting PRs

You are free to submit PRs for bug fixes and enhancements to godot-object-compiler. Any PR must have a corresponding issue describing bug or
feature, which should be confirmed or accepted by a contributor to ensure alignment with the current development.

In absense of a concrete style guide *for now*, code contributions must follow these general rules:
* Adhere to the predominant coding style
* Apply formatting and generate licence headers
* Accept contributors guidance

If tooling is present in the PR workflow:
* 100% test success rate is required before merging
* Overall test coverage must not decrease
* Issues reported by static analysers must be fixed (or accepted by a maintainer) before merging.

## AI Policy

* Do **not** write issue or PR description/comments using AI Tools. Understanding the task and submitted implementation is the baseline of any contribution.
* Use AI Tools during developement in any way that helps, but **thoroughly review your contribution** before submitting a PR.

## Using godot-object-compiler in your project

Using godot-object-compiler in your project is in itself a contribution. If you do so, feel free to message [the maintainer](https://github.com/LucaTuerk)
about your experience, or if you think your project should be featured.
