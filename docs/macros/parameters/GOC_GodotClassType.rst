GOC_GodotClassType
^^^^^^^^^^^^^^^^^^

This parameter type is used to set the classes type in the GODOT_CLASS macro parameters.

The following values are available:

+----------------+----------------------------+
| Value          | Description                |
+================+============================+
| RegisterCustom | No documentation available |
+----------------+----------------------------+
| GodotClass     | No documentation available |
+----------------+----------------------------+
| VirtualClass   | No documentation available |
+----------------+----------------------------+
| AbstractClass  | No documentation available |
+----------------+----------------------------+
| InternalClass  | No documentation available |
+----------------+----------------------------+
| RuntimeClass   | No documentation available |
+----------------+----------------------------+
