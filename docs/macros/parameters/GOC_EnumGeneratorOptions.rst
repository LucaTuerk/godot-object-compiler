GOC_EnumGeneratorOptions
^^^^^^^^^^^^^^^^^^^^^^^^

This parameter type is used to provide options to the enum generator in the GODOT_ENUM macro parameters.

The following values are available:

+-------------+--------------------------------------------------------------------------------------------------+
| Value       | Description                                                                                      |
+=============+==================================================================================================+
| EnumDefault | Bind this enum as a regular enum.                                                                |
|             | This is the default value.                                                                       |
+-------------+--------------------------------------------------------------------------------------------------+
| EnumFlags   | Bind this enum as a bitfield enum and display properties of this type as flags in the inspector. |
+-------------+--------------------------------------------------------------------------------------------------+
