GOC_PropertySetability
^^^^^^^^^^^^^^^^^^^^^^

This parameter type is used to set the properties ability to be set from scripts.

The following values are available:

+-------------+------------------------------------------------------------------------------------------------------------------+
| Value       | Description                                                                                                      |
+=============+==================================================================================================================+
| SetAnywhere | This property can be set from scripts. This is the default value.                                                |
+-------------+------------------------------------------------------------------------------------------------------------------+
| Readonly    | This property is readonly and cannot be set in scripts, initialization values set in the editor will be applied. |
+-------------+------------------------------------------------------------------------------------------------------------------+
