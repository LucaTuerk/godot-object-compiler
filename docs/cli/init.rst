init
====

Interactively initialize a new GOC project in the current working
directory. Aborts if a GOC project index (\*.goc_project) is already present.

**NOTE:** a godot-cpp project or template should already be in place before using this command.

Usage
-----

.. code-block:: bash

    $ goc init

Takes no arguments.
